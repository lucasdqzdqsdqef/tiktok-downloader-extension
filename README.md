How to Install the TikTok Downloader

Open the Extensions Page:
Open Google Chrome (or any Chromium-based browser like Brave or Edge).
Type chrome://extensions/ into the URL bar and press Enter.
Enable Developer Mode:

Look in the top right corner of the page.
Toggle the switch that says "Developer mode" (Mode développeur) so that it is turned ON.
Load the Extension:

A new menu bar will appear at the top left of the screen.
Click the button that says "Load unpacked" (Charger l'extension non empaquetée).
Select Your Folder:

A file explorer window will open. Navigate to the folder where the extension code is saved
Click the folder to highlight it, then click "Select Folder".

Pin It! (Optional but recommended):
Click the grey puzzle piece icon in the top right corner of Chrome (next to your profile picture).
Find "TikTok Downloader" in the list and click the Pin icon so the logo stays permanently visible on your toolbar.
